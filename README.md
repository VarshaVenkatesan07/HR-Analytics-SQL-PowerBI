# HR Analytics using SQL & Power BI

## Project Overview

This project analyzes employee data to identify workforce trends and provide insights that help HR teams make data-driven decisions. The project includes SQL-based data cleaning and analysis, followed by an interactive Power BI dashboard.

## Objectives

- Clean and validate HR employee data using SQL.
- Perform exploratory data analysis (EDA).
- Analyze employee attrition and workforce demographics.
- Create HR KPIs and business insights.
- Build an interactive Power BI dashboard.

## Tools & Technologies

- MySQL
- Power BI
- SQL
- Microsoft Excel (Dataset)

## Dataset

The dataset contains employee information such as:

- Age
- Gender
- Department
- Job Role
- Education
- Monthly Income
- Job Satisfaction
- Performance Rating
- Years at Company
- Attrition
- Overtime
- Work-Life Balance
- Business Travel
- Marital Status

## Key Metrics

- Total Employees
- Attrition Rate
- Active Employees
- Average Age
- Average Monthly Income
- Average Years at Company
- Job Satisfaction
- Overtime Percentage

## Business Questions

- Which department has the highest attrition?
- Which job role has the highest employee turnover?
- Does overtime affect attrition?
- How does work-life balance impact employee retention?
- Which age group has the highest attrition?
- Which departments have the highest average salary?
- What factors contribute most to employee attrition?
